# 계산 계약

모든 금액은 부가세 포함 원 단위 정수이며 연이율·선택약정률은 소수 둘째 자리까지 입력할 수 있습니다. 기간은 0~120의 정수이며 비교 기간은 1~120개월입니다. 실제 UI 주 비교는 24/36개월입니다.

## 기기

- net: 판매가격/할부원금 그대로 사용, 할인 입력은 다시 차감하지 않음.
- gross: 판매가격에서 기기 할인·통신사 지원금·판매점 지원·쿠폰·기타 확정 할인을 차감.
- 할인 합계가 gross 가격을 넘으면 입력 오류. 최종 원금의 경우 출고가보다 높다고 자동 할인하거나 변경하지 않음.
- 현금 페이백·미래 반납금은 실제 확정 할인으로 처리하지 않음.

## 월별

- 월 m ≤ 유지기간: 초기 요금. 그 외: 이후 요금.
- 선택약정 활성화 및 m ≤ 적용기간: 대상 월정액 × 할인율을 원 단위 반올림해 차감.
- 각 부가서비스와 보험은 해당 가입 개월까지만 합산.
- 카드 할인은 적용기간 동안 월별 차감, 연회비는 해당 기간 내 1·13·25…개월에 가산. 실적 충족 가정이며 추가 소비는 제외.

## 할부

일시불은 첫 달 원금 전액. 연이율 모드는 월 이율 r=연이율/1200으로 원리금균등 상환. 첫 이자는 남은 원금×r, 원금분은 월 상환액에서 이자를 제외. 원 단위로 반올림하고 마지막 달에 남은 원금을 정산합니다. 무이자 및 총 수수료 모드는 누적액 반올림 차분을 이용해 합계가 정확히 원금/수수료와 같도록 배분합니다.

## 결과

기간 내 지출 = 월별 실제 납부액 합계.

비교 총비용 = 기간 내 지출 + 비교기간 종료 시 미납 원금.

월평균 부담 = 비교 총비용 ÷ 개월 수.

기간 이후 발생할 미래 이자는 비교 총비용에서 제외하고 별도 안내합니다. 할부 계약 전체를 끝까지 유지하면 해당 이자가 더 발생합니다. 조기 상환 수수료·위약금은 자동 계산하지 않습니다.

도넛은 카드 청구할인을 차감하기 전의 양수 비용 비중입니다. 카드 할인 때문에 음수 총액이 되는 입력도 그대로 보여주되 조건부 할인 경고를 표시합니다. 이는 현실적인 계약임을 보증하지 않습니다.

## 저장과 공유

최대 저장 50개, 비교 3개, 부가서비스 30개. 저장소 실패·손상 항목은 사용자가 알 수 있도록 처리하며 유효한 항목만 읽습니다. 입력 텍스트는 HTML escape 후 렌더링합니다. 공유 payload는 버전과 표준 견적 필드만 허용합니다. URL hash에 Base64URL JSON을 담으며 사용자 자유입력 이름들은 일반 문자열로 대체합니다. 저장 링크를 서버로 전송하지 않습니다.
