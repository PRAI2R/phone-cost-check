기존 서비스의 화면이나 문구를 복제하지 않았습니다. 흰 카드와 청록색, 비용 영수증 형태의 예시, 어두운 총액 카드를 중심으로 새 UI를 작성했습니다. 수익률·상품 추천보다 지출 구조를 설명하는 방식입니다.

## 정책 확인

- [과학기술정보통신부의 2025-07-23 안내](https://www.korea.kr/multi/visualNewsView.do?newsId=148953626): 2025-07-22 법 폐지, 지원금 공시 의무·추가지원금 상한 폐지, 선택약정 유지. 사이트에서는 과거 추가지원금 15% 상한을 적용하지 않습니다.
- [스마트초이스 선택약정 안내](https://www.smartchoice.or.kr/smc/service/danpageNew.do): 25% 요금할인과 통신사 지원금 비교, 판매점 추가지원금 구분. 실제 가입 가능 여부는 조회 결과와 계약에 따릅니다.

2026년 확인 시 접근 가능한 공식 안내를 사용했습니다. 이것을 모든 상품의 2026년 요율이나 계약 조건이 확인됐다는 뜻으로 확대하지 않습니다. 할부 5.9%는 사용자 수정 가능한 **입력 예시**이며 모든 통신사의 현행 수수료로 주장하지 않습니다.

## 줄이려는 사용자 오류

1. 할인 후 원금에서 지원금을 다시 차감하는 오류 → net/gross 모드 구분.
2. 36개월 할부를 24개월 납부액으로만 평가하는 오류 → 남은 원금 별도·총액 포함.
3. 선택약정이 36개월 내내 자동 연장된다고 가정하는 오류 → 적용기간 입력, 기본 24개월.
4. 카드 실적·연회비를 무시하는 오류 → 조건부 혜택 표시와 할인 미반영 총액 안내.
5. 총액만 보고 비용이 내려가는 시점을 놓치는 오류 → 월별 그래프와 표.
