## 발견하여 수정한 문제

1. 모바일 계산 결과의 넓은 표가 grid 최소 폭을 키움 → grid 자식 `min-width:0`, 단일 열 `minmax(0,1fr)` 적용. 변경 후 문서 가로 폭이 뷰포트 가용 폭과 동일함을 확인.
2. 이미 열린 계산기에서 공유 hash만 바뀌면 입력이 갱신되지 않음 → hashchange 처리 추가.
3. 브라우저 기본 prompt/confirm에 의존한 이름 변경·확인 흐름 → 키보드로 조작 가능한 HTML dialog로 교체하고 변경·삭제 재검수.
4. 제한된 실행 환경에서 Node 테스트 격리 프로세스가 생성되지 않음 → 동일 node:test 테스트를 직접 실행하는 `npm test`로 조정.
5. Cloudflare CSP와 JSON-LD → 생성된 구조화 데이터의 SHA-256 hash를 허용 목록에 포함.
